# verilog-ethernet (imported)

Subset of https://github.com/alexforencich/verilog-ethernet (MIT license, see
COPYING), commit 77320a9471d19c7dd383914bc049e02d9f4f1ffb (2025-02-27).
Files are unmodified. Used by Eth_Host_Link: RGMII MAC with FIFOs
(eth_mac_1g_rgmii_fifo) and the UDP/IP/ARP stack (udp_complete).

The .tcl files are Vivado constraint scripts from the same commit; they add
the CDC constraints for these modules and are sourced from constrs_2.
